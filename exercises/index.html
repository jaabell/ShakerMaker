    Exercises¶

    A graded path through ShakerMaker. Each exercise is a complete, runnable script plus the result you should see and how to read it. They build on each other, do them in order the first time.

    Every exercise maps to a folder under examples/, so the script and the figures you see here are the ones that actually ran.

    # Exercise You learn Example folder
    1 First run & the four arrivals the full pipeline; reading a seismogram 05_engine_direct
    2 Numerical convergence what dk and nfft actually control 05_engine_direct
    3 A sedimentary basin how layering shapes motion; resonance 01_crustmodel
    4 Source time functions compared choosing an STF for a target band 03_stf
    5 DRM box → H5DRM boundary motions for OpenSees 08_drm
    6 FFSP stochastic rupture an ensemble of admissible ruptures 10_ffsp
    7 Receiver geometries & the fast pipeline array layouts; Green's-function reuse 04_receivers, 06_nearest_method
    8 Sources: point & finite faults mechanisms; building a finite fault 02_sources
    9 Saving results & writers .npz, HDF5, progressive mode 07_writers
    10 Exporting to SW4 hand a model to SW4 and back 09_sw4_export
    11 Plotting & visualisation ZENTPlot, StationPlot, SourcePlot 11_plotting
    12 Validation: SCEC LOH.1 the benchmark that proves it's correct 12_validation
    13 ShakerMaker vs SW4 cross-validation against finite-difference 13_shakermaker_sw4

    How to run

    Each script is self-contained, copy it into a .py file and run with python exercise.py. On a workstation the FK examples finish in seconds; the FFSP, DRM, and fast-pipeline ones take longer. For large jobs, launch under MPI: mpirun -n 8 python exercise.py.
